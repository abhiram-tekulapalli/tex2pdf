# Tex — Unpacked Chrome Extension (Manifest V3)

## Quick Load Instructions (`chrome://extensions`)

1. Open Chrome and navigate to `chrome://extensions`.
2. Toggle **Developer mode** ON (top right).
3. Click **Load unpacked** (top left).
4. Select this `tex/` directory (or the `dist/` directory generated by `npm run build` in the project root).
5. Click the **Tex** icon in your Chrome extensions toolbar to paste LaTeX source code, compile to PDF locally, preview, and download `document.pdf`.
